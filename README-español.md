# Filtro-Solar-app ☀️

## 👋 ¡Bienvenido al proyecto!

Este es el repositorio oficial de la aplicación móvil **Filtro-Solar-app**, un proyecto tecnológico desarrollado específicamente para mi **feria de ciencias escolar**.

La aplicación combina un entorno web moderno con un contenedor móvil mediante la tecnología **Capacitor**, ofreciendo una experiencia fluida e interactiva.

---

## 📦 ¿Dónde está el archivo de instalación (APK)?

Si buscas el instalador directo para probar la aplicación en tu teléfono móvil, no es necesario compilar nada a partir del código fuente. El archivo ejecutable ya se encuentra disponible en este repositorio.

Puedes encontrar el instalador y su guía de uso específica en la siguiente ruta:
👉 `https://github.com/eitfabrizio/Filtro-Solar-app/releases/tag/APK`

Allí encontrarás:
* 📱 **`app-release.apk`**: El archivo instalador final para tu teléfono.
* 📄 **`README.md`**: Un manual con instrucciones específicas para dispositivos móviles, que explica paso a paso cómo omitir las restricciones de seguridad de Android (Play Protect).

---

## 💻 Instrucciones de ejecución (Solo para computadoras)

Para abrir y ejecutar el proyecto en tu computadora en modo de desarrollo, debes ejecutar los siguientes dos comandos en tu terminal:

1. **Instalar dependencias:** Abre la terminal en la carpeta raíz del proyecto y descarga los módulos necesarios ejecutando:
   ```bash
   npm install
   ```

2. **Iniciar el proyecto:** Inicia el servidor y pon en marcha la aplicación automáticamente con el comando:
   ```bash
   npm start
   ```
